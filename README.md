# 입고 예정 PLT Dashboard

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 사용 순서

1. PU 월별 Excel/CSV 업로드
2. 분석 월 선택
3. 필요하면 `라인,창고` 매핑 파일 업로드
4. 원본 PCS와 변환 PCS 검증
5. 5개 PLT 차트 확인
6. 변환된 입고 DATA CSV 다운로드

현재 PU 원본의 날짜 헤더는 `9. 1`, `09.01`, `9월 1일`, `2026-09-01` 등의 형태를 자동 인식하며 `협의중`, `합계`, `S&OP`, `누계` 등은 제외합니다.

PLT 기본 계산은 `ROUNDUP(입고 PCS / 팔레트당 PCS, 0)`입니다. 실제 업무 기준이 다르면 사이드바에서 올림을 해제하거나 계산식을 수정하세요.

회사 데이터를 외부 서비스에 올릴 경우 회사 보안정책을 확인하고, 초기 검증은 로컬 실행을 권장합니다.
